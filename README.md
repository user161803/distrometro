# Distrómetro

Test humorístico de 8 preguntas que te recomienda tu distribución de Linux ideal entre 13 candidatas (Linux Mint, Ubuntu, Zorin OS, elementary OS, Fedora, Pop!_OS, Bazzite, Manjaro, openSUSE Tumbleweed, Debian, MX Linux, Arch y NixOS). Muestra cómo es la distro, por qué encaja contigo, su ficha técnica y un enlace a la descarga oficial de la ISO. De paso, se queja de todo lo que hace mal Windows.

## Uso

Es un único archivo HTML estático, sin dependencias ni compilación. Ábrelo en el navegador:

```bash
xdg-open index.html
```

O publícalo con GitHub Pages (Settings → Pages → rama `main`, carpeta raíz).
