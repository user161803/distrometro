# Distrómetro

Test humorístico de 11 preguntas que te recomienda a la vez tu distribución de Linux y tu escritorio ideales entre 32 candidatas (Linux Mint, Ubuntu, Kubuntu, Zorin OS, elementary OS, Linux Lite, MX Linux, Puppy Linux, Fedora, Fedora Silverblue, Pop!_OS, Ubuntu Studio, Bazzite, Nobara, CachyOS, Garuda Linux, Manjaro, EndeavourOS, Arch, openSUSE Tumbleweed, Debian, AlmaLinux, Alpine, Void Linux, Gentoo, Slackware, NixOS, Kali Linux, Tails, Qubes OS, Fedora Asahi Remix y Raspberry Pi OS). Muestra cómo es la distro, por qué encaja contigo, su ficha técnica y un enlace a la descarga oficial de la ISO. De paso, se queja de todo lo que hace mal Windows.

Incluye además:

- 20 escritorios y gestores de ventanas: GNOME, KDE Plasma, Cinnamon, Xfce, MATE, LXQt, Budgie, COSMIC, Pantheon, Enlightenment, Hyprland, niri, i3 y Sway, awesome, bspwm, dwm, Qtile, Openbox, IceWM y labwc.
- Un catálogo de escritorios con ficha, captura (salvo niri y Qtile, que no tienen capturas libres en Commons) y enlace propio para cada uno (por ejemplo [`#kde`](https://user161803.github.io/distrometro/#kde)).
- Capturas de pantalla de cada distro y de cada escritorio.
- Un catálogo para explorar todas las distros, con filtros por dificultad.
- Un enlace propio para cada distro, por ejemplo [`#arch`](https://user161803.github.io/distrometro/#arch).
- Una guía paso a paso para instalar Linux, equivalencias de programas y una lista sincera de lo que todavía no funciona.

## Uso

Es un único archivo HTML estático, sin dependencias ni compilación. Ábrelo en el navegador:

```bash
xdg-open index.html
```

Versión publicada: https://user161803.github.io/distrometro/

## Créditos

Los logos de las distribuciones proceden de [Simple Icons](https://simpleicons.org/) (CC0) y, en el caso de Bazzite, Ubuntu Studio, Linux Lite y Puppy Linux, de sus webs oficiales. Los escritorios sin logo descargable se muestran con sus iniciales. Todas las marcas y logos pertenecen a sus respectivos propietarios.

Las capturas de pantalla de la carpeta `shots/` proceden de [Wikimedia Commons](https://commons.wikimedia.org/). La mayoría tienen licencia GPL, LGPL o BSD; las de MX Linux y Hyprland son CC BY 4.0, las de Kali Linux, i3 e IceWM son CC BY-SA 4.0 y la de dwm es de dominio público. El autor y la licencia de cada una aparecen bajo la imagen en la web y en los objetos `SHOTS` y `DE_FETCHED` de `index.html`.
