# Distrómetro

Test humorístico de 8 preguntas que te recomienda tu distribución de Linux ideal entre 23 candidatas (Linux Mint, Ubuntu, Kubuntu, Zorin OS, elementary OS, Linux Lite, MX Linux, Fedora, Pop!_OS, Ubuntu Studio, Bazzite, CachyOS, Manjaro, EndeavourOS, Arch, openSUSE Tumbleweed, Debian, AlmaLinux, Void Linux, Gentoo, NixOS, Kali Linux y Tails). Muestra cómo es la distro, por qué encaja contigo, su ficha técnica y un enlace a la descarga oficial de la ISO. De paso, se queja de todo lo que hace mal Windows.

## Uso

Es un único archivo HTML estático, sin dependencias ni compilación. Ábrelo en el navegador:

```bash
xdg-open index.html
```
